# Player race and class are neutralised in audio, not voiced per variant

`$N`, `$R` and `$C` are replaced with a Neutral Address ("friend", "adventurer") in the spoken audio, while the on-screen text keeps the real word. Generating one variant per playable race and class would multiply lines, and it can't anticipate Forever's new Skyborne race or new race/class combinations. Only player gender (`$G`) still produces two voiced variants.
