# NPC audio is VoxCPM2 continuation from a hand-picked anchor

Four bake-off rounds (#10) found that only VoxCPM2 voice design gives fantasy races (orcs, trolls) the right accent and character. But designing each line from a description drifts: every line sounds like a different speaker. Cloning a reference, with VoxCPM2 or with Chatterbox, OmniVoice, Fish or Seed-VC, keeps the identity but loses the character, and anchors auto-picked by pitch lost it too. What works is a human picking, by ear, the design candidate that has the character, then generating every line as a VoxCPM2 continuation of that anchor. That kept both identity and character on every voice tested. So the Approval Gate picks anchors, not voice settings, and no other TTS model is used for NPCs. Kokoro stays for the Narrator.
